# Unit 2 Chapter 3 Question 1 - Lowest and Highest
Find the lowest and highest integers in a user-inputted set of numbers. 

## Input Specification
The first line of input, $N$, represents how many numbers there are, where $1 \le N \le 100$.

The next $N$ lines will contain an integer. 

## Output Specification
Output 2 lines, as follows (the square brakcets are not printed):

```
min: [minimum]
max: [maximum]
```

## Sample Input 1

```
3
100
-98
0
```

## Sample Output 1

```
min: -98
max: 100
```


## Sample Input 2

```
5
14
29
44
1
243
```

## Sample Output 2

```
min: 1
max: 243
```
