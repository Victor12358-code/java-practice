# Unit 2 Chapter 3 Question 2 - Wheel of Fortune
In 1988, it was realized by the producers of the game show *Wheel of Fortune* that the most common letters chosen by players in the Bonus Round were the letters R, S, T, L, N, and E. 
[marketrealist.com](https://marketrealist.com/why-does-wheel-of-fortune-give-r-s-t-l-n-e-for-free-to-bonus-round-contestants/)

Find the occurrences of these six letters for a user-inputted string, $S$. Both capital and lowercase letters should be counted.


## Input Specification
The input consists of a single line containing a String, $S$. It is guaranteed that the length of $S$ will be $>= 1$.

## Output Specification
Output the number of occurrences for each of the letters that are provided to the player at the start of the Bonus Round in *Wheel of Fortune*, following the order given on the show (R, S, T, L, N, E). Output the occurrences using the format `[letter]: [num]`, with the square brackets ommitted. 

## Sample Input 1

```
The quick brown fox jumps over the lazy dog. 
```

## Sample Output 1

```
R: 2
S: 1
T: 2
L: 1
N: 1
E: 3
```

## Explanation for Sample Output 1

The phrase `the quick brown fox jumps over the lazy dog` is a well-known English pangram, which is a phrase that contains all of the letters in a particular alphabet. 

There are 2 occurrences of the letter `T`, as both uppercase and lowercase instances should be counted.

## Sample Input 2

```
Seventeen
```

## Sample Output 2

```
R: 0
S: 1
T: 1
L: 0
N: 2
E: 4
```

## Explanation for Sample Output 2

Despite what AI might think, there are indeed 4 letter 'E's in the word 'seventeen'. See [Husk IRL | YouTube](https://youtu.be/A3fHWl6hiFE?si=hvuXaN0UpJzUjfjo&t=257) for the reference.
