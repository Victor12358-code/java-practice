# Unit 2 Chapter 2 Question 3 - Doom Guy
In the original Doom and Doom II, Doom guy's face in the centre of the status bar would change depending on the amount of health the player has. This was useful as a quick visual reference for how close the player was to dying.

Your task is to output the state of Doom Guy's face depending on the amount of health $H$ the player has.

## Input Specification
The input consists of a single line containing an integer, $H$. It is guaranteed that $0 \le H \le 300$, as the most health the player could get was $300 \%$ of their original health.

## Output Specification
Output a description of Doom Guy's face based on his health, $H$.
- If $H \ge 80\% \text{ and } \le 300\%$, Doom Guy is completely health. Output `healthy`.
- If $H \ge 60\% \text{ and } \le 79\%$, output `bloody nose`.
- If $H \ge 40\% \text{ and } \le 59\%$, output `face swollen`.
- If $H \ge 20\% \text{ and } \le 39\%$, output `eyes bloodshot, face bleeding`.
- If $H \ge 1\% \text{ and } \le 19\%$, output `even more blood`.
- If $H$ is $0\%$, output `eyes closed. Game Over`.

## Sample Input 1

```
100
```

## Sample Output 1

```
healthy
```

## Explanation for Sample Output 1

With his health at $100\%$, Doom Guy is at his maximum health without bonuses, so he is `healthy`.

## Sample Input 2

```
0
```

## Sample Output 2

```
eyes closed. Game Over
```

## Explanation for Sample Output 2

As Doom Guy has reached $0\%$ health, he is now dead. His sprite changes so that his eyes are closed, and the game is over.
