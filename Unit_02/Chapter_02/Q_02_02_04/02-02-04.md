# Unit 2 Chapter 2 Question 4 - ATM Withdrawal
Write a program that simulates an ATM withdrawal. The ATM system requires that users reset their 4-digit PINs every 6 months. 

Assume that each user of the program has $500 in their chequing accounts, and that the daily withdrawal limit is $250. 


## Input Specification

The first line of input contains the user's new numeric-only PIN code $P$, where the PIN has between 0 and 10 characters. PINs may start with 0. If the new PIN is invalid, the program ends and no further input is given. The second line contains the PIN that the user is using to access their chequing account, $P_{1}$, where  the PIN also has between 0 and 10 characters. If the entered PIN is invalid, the program ends and no further input is given. The third line contains a positive integer, $M$, the amount of money that the user wants to withdraw from their account.

## Output Specification

When the user is entering their new PIN, they will either successfully enter a 4-digit PIN, and the ATM will respond with `New PIN stored.`, or they will enter a PIN that is not 4 digits, at which point the ATM will output `Invalid PIN length entered. Goodbye.`. 

When the user is entering their PIN to access their account, they will need to enter the 4-digits of the new PIN that they just set. If they enter a PIN that is more or less than 4 digits, the ATM outputs `Invalid PIN length entered. Goodbye.` If they enter an incorrect 4-digit PIN, the ATM outputs `Invalid PIN entered. Goodbye.`. 

If the user enters the correct PIN, they will then enter the amount of cash they wish to withdraw. The ATM first checks if that amount is more than the user's account balance. If it is, the ATM outputs `Insufficient funds. Goodbye.`. The ATM then checks if the amount to withdraw is more than the daily allowed limit. If it is, the ATM outputs `Exceeds daily limit. Goodbye.`.

Otherwise, the ATM outputs `Withdrawal approved.`. On the next line, it outputs the new balance in the user's account by outputting `Balance: $` followed by the user's new balance.

## Sample Input 1

```
0001
0001
240
```

## Sample Output 1

```
New PIN stored.
Withdrawal approved.
Balance: $260
```

## Explanation for Sample Output 1
The user entered a valid new PIN, `0001`, then immediately entered the PIN again to access their account. They requested a withdrawal of $240, which the ATM was able to process as they have sufficient funds and that amount is less than the daily withdrawal limit.
