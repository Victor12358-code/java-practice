# Unit 2 Chapter 2 Question 2 - The Greatest Footballer
Two of the modern greats of European football are Lionel Messi and Cristiano Ronaldo. Fans from Argentina undoubtedly think that Messi is better, while fans from Portugal side with Ronaldo. If a fan is not from either country, they do not prefer either footballer.

Your task is to determine which footballer someone prefers based on their country of origin, $C$. 

## Input Specification
The input consists of a single line containing a String, $C$. It is guaranteed that $C.length() >= 1$.

## Output Specification
Output the best footballer for the input $C$.
- If $C$ is `Argentina`, output `Lionel Messi`.
- If $C$ is `Portugal`, output `Cristiano Ronaldo`.
- If $C$ is any other input, output `no preference`.
- 

## Sample Input 1

```
Argentina
```

## Sample Output 1

```
Lionel Messi
```

## Explanation for Sample Output 1

An Argentinian's preferred footballer is Lionel Messi. Thus, the output was `Lionel Messi`. 

## Sample Input 2

```
Peru
```

## Sample Output 2

```
no preference
```

## Explanation for Sample Output 2

As Cristiano Ronaldo is from Portugal and Lionel Messi is from Argentina, a football fan from Peru has no preference between the two. Thus, the output was `no preference`.
